### FILE — `src/core/exceptions.py`

The single source of domain exceptions for the whole project. Services and repositories raise these; a FastAPI exception handler elsewhere maps them to HTTP status codes. This module therefore must stay framework-free.

**Base class `AppError(Exception)`**

- Signature: `__init__(self, message: str | None = None, details: dict[str, Any] | None = None) -> None`.
- A class-level attribute holds the default message. When `message` is not supplied, the instance falls back to that default, so `raise NotFoundError()` produces a sensible message.
- Stores the resolved message and the details as instance attributes (`message`, `details`). `details` is always a `dict[str, Any]` — an empty dict when nothing was passed, never `None`.
- Passes the resolved message to `super().__init__`.
- `AppError`'s own default message: `Application error.`

**Subclasses** — each inherits directly from `AppError`, adds nothing but its own default message, and has a docstring saying when it should be raised:

| Class | Default message |
|---|---|
| `ValidationError` | `Validation failed.` |
| `NotFoundError` | `Requested resource was not found.` |
| `ConflictError` | `Resource conflict.` |
| `AuthenticationError` | `Authentication failed.` |
| `PermissionDeniedError` | `Not enough permissions.` |
| `TokenExpiredError` | `Token has expired.` |
| `ExternalServiceError` | `External service is unavailable.` |
