### FILE 1 — `src/models/accounts.py`

All classes inherit `Base` plus the mixins named below. Every class sets `__tablename__` explicitly. Enum columns use `SQLEnum(...)` imported as `from sqlalchemy import Enum as SQLEnum`. Relationships use `Mapped[...]` / `relationship(...)` with explicit `back_populates` on both sides.

#### `UserGroup` — table `user_groups`

Mixins: `IntPKMixin`.

| Column | Type | Constraints |
|---|---|---|
| `id` | `int` | PK, from `IntPKMixin` |
| `name` | `UserGroupEnum` | `SQLEnum(UserGroupEnum)`, `unique=True`, `nullable=False` |

Relationship: `users` — one-to-many to `User`, `back_populates="group"`. No cascade delete: a group outlives its users.

#### `User` — table `users`

Mixins: `IntPKMixin`, `TimestampMixin`.

| Column | Type | Constraints |
|---|---|---|
| `id` | `int` | PK, from `IntPKMixin` |
| `email` | `String(255)` | `unique=True`, `nullable=False`, `index=True` |
| `hashed_password` | `String(255)` | `nullable=False` |
| `is_active` | `bool` | `nullable=False`, `default=False`, `server_default=false()` |
| `created_at`, `updated_at` | `datetime` tz-aware | from `TimestampMixin` |
| `group_id` | `int` | `ForeignKey("user_groups.id", ondelete="RESTRICT")`, `nullable=False` |

Use `from sqlalchemy import false` for the server default; do not pass the string `"false"`.

Relationships:

- `group` → `UserGroup`, many-to-one, `back_populates="users"`
- `profile` → `UserProfile`, one-to-one: `uselist=False`, `back_populates="user"`, `cascade="all, delete-orphan"`
- `activation_token` → `ActivationToken`, one-to-one: `uselist=False`, `back_populates="user"`, `cascade="all, delete-orphan"`
- `password_reset_token` → `PasswordResetToken`, one-to-one: `uselist=False`, `back_populates="user"`, `cascade="all, delete-orphan"`
- `refresh_tokens` → `RefreshToken`, one-to-many, `back_populates="user"`, `cascade="all, delete-orphan"`

#### `UserProfile` — table `user_profiles`

Mixins: `IntPKMixin`.

| Column | Type | Constraints |
|---|---|---|
| `id` | `int` | PK |
| `user_id` | `int` | `ForeignKey("users.id", ondelete="CASCADE")`, **`unique=True`**, `nullable=False` |
| `first_name` | `String(100)` | nullable |
| `last_name` | `String(100)` | nullable |
| `avatar` | `String(255)` | nullable — an S3 object key, not a URL |
| `gender` | `GenderEnum` | `SQLEnum(GenderEnum)`, nullable |
| `date_of_birth` | `Date` | nullable |
| `info` | `Text` | nullable |

Nullable columns are annotated `Mapped[str | None]` (and so on) with `nullable=True`.

Relationship: `user` → `User`, `back_populates="profile"`.

#### `ActivationToken` — table `activation_tokens`

Mixins: `IntPKMixin`, `TokenMixin`.

| Column | Type | Constraints |
|---|---|---|
| `user_id` | `int` | `ForeignKey("users.id", ondelete="CASCADE")`, **`unique=True`**, `nullable=False` |

Relationship: `user` → `User`, `back_populates="activation_token"`.

#### `PasswordResetToken` — table `password_reset_tokens`

Identical shape to `ActivationToken`: `IntPKMixin` + `TokenMixin`, `user_id` **`unique=True`**, `ondelete="CASCADE"`, `nullable=False`. Relationship `user`, `back_populates="password_reset_token"`.

#### `RefreshToken` — table `refresh_tokens`

Mixins: `IntPKMixin`, `TokenMixin`.

| Column | Type | Constraints |
|---|---|---|
| `user_id` | `int` | `ForeignKey("users.id", ondelete="CASCADE")`, **NOT unique**, `nullable=False` |

A user may hold several concurrent sessions, so this is the one `user_id` in the module without a uniqueness constraint. Relationship: `user` → `User`, `back_populates="refresh_tokens"`.
