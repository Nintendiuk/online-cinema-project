### FILE — `src/db/enums.py`

A module holding the project's domain enumerations. It imports **nothing but `enum`** from the standard library and nothing at all from the project.

Both enumerations inherit from `str` and `Enum` — declared as `class X(str, Enum)` — so that FastAPI and Pydantic v2 serialise them to plain JSON strings without any custom encoder.

**`UserGroupEnum`** — the access groups a user can belong to:

| Member | Value |
|---|---|
| `USER` | `"user"` |
| `MODERATOR` | `"moderator"` |
| `ADMIN` | `"admin"` |

**`GenderEnum`** — the gender stored on a user profile:

| Member | Value |
|---|---|
| `MAN` | `"man"` |
| `WOMAN` | `"woman"` |

Rules:

- The string values are fixed. They are persisted in PostgreSQL as native enum types and are referenced by later phases, so neither the member names nor the values may be altered, reordered, or extended.
- Member order is exactly as listed in the tables above.
- Each enumeration gets an English docstring stating what it represents and where it is stored.
- The module gets a module-level docstring.
- No methods, no `_missing_`, no `@classmethod` helpers, no `__all__`, no aliases, no extra members such as `OTHER` or `UNKNOWN`.
- Do not use `enum.StrEnum` — the project targets a declaration style shared with SQLAlchemy's `SQLEnum(...)`, which is fed the class as written above.
