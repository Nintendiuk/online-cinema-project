do not re-declare the validator.

```python
class _EmailNormalizingSchema(BaseModel):
    """Base for request schemas carrying an ``email`` field."""

    model_config = ConfigDict(extra="forbid")

    email: EmailStr

    @field_validator("email", mode="before")
    @classmethod
    def _normalize_email(cls, value: object) -> object:
        if isinstance(value, str):
            return normalize_email(value)
        return value
```

So your module starts from:

Subclassing a private name across modules is intentional here: e-mail

Note that a subclass which declares its own `model_config` **replaces** the
parent's, so any subclass of `_EmailNormalizingSchema` that sets
`json_schema_extra` must also re-state `extra="forbid"`.

### Rules

1. **Every request schema sets `extra="forbid"`.** An unexpected key must produce
   422, not be silently dropped.
2. **Every schema carries `json_schema_extra` with a realistic example.** Use a
   truncated but shaped JWT for token examples, e.g.
   `"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VyX2lkIjoxfQ.5m0kQ..."`.
3. **No password strength validation in `LoginRequestSchema`.** Login must accept
   whatever the user types and fail with **401**, not 422. Only registration
   validates strength. Do not add `min_length` to the login password either —
   a length rule would turn a wrong short password into a 422 and leak that the
   password rules were not met.
4. `token_type` is a literal default of `"bearer"`, never a required input. Type
   it as `str` with the default; do not use `Literal`.
5. Response schemas are read models. They do not need `from_attributes` — the
   service returns plain strings, not ORM objects — so do not set it.
6. Module layout: module docstring first, then imports, then a sorted
   `__all__` list containing the five public schema names (`_EmailNormalizingSchema`
   is not exported from here), then the classes.
7. Requests before responses is not required; order the classes so that the
   login pair reads top to bottom: `LoginRequestSchema`, `TokenPairResponseSchema`,
   `AccessTokenResponseSchema`, `RefreshRequestSchema`, `LogoutRequestSchema`.
