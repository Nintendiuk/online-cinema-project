### 2. `src/integrations/email/templates/activation_request.html`

Self-contained HTML e-mail. Requirements:

- **Inline CSS only** — `style="..."` attributes on the elements. Mail clients strip
  `<style>` blocks and ignore external stylesheets.
- **Table-based layout, 600 px wide**, centred. No flexbox, no grid, no `<div>`-only
  layout: Outlook will not render it.
- No external images, no `<script>`, no web fonts, no tracking pixels.
- Jinja2 placeholders `{{ email }}` and `{{ activation_link }}`.
- Address the recipient by `{{ email }}`.
- A **prominent call-to-action button** linking to `{{ activation_link }}` — build it as
  a table cell with a background colour and padding wrapping an `<a>`, not as a styled
  `<button>` (buttons do not work in e-mail).
- State clearly that the link is **valid for 24 hours**.
- A **plain-text fallback line** below the button showing the full `{{ activation_link }}`
  URL as selectable text, introduced by wording such as "If the button does not work,
  copy this address into your browser".
- A closing line telling the recipient to ignore the message if they did not register.
- `<!DOCTYPE html>`, `<html lang="en">`, `<meta charset="utf-8">`, and a
  `<meta name="viewport" ...>` for mobile clients.
- A `<title>` element.
